# QuickCook — Nền Tảng Thực Phẩm Sơ Chế & Minh Bạch Nguồn Gốc
> Đồ án Khởi nghiệp đổi mới sáng tạo — EXE101 | Đại học FPT

Website thương mại điện tử cung cấp các combo nguyên liệu sơ chế sạch, định lượng chuẩn cho bữa cơm gia đình, tiên phong ứng dụng **Hệ thống minh bạch nguồn gốc & Giấy chứng nhận chất lượng (VietGAP / HACCP / Kiểm dịch thú y)**, **Cổng thanh toán tự động VietQR (Napas 247)** và **Bảng điều khiển quản trị (Admin Dashboard)**.

---

## ⚡ HƯỚNG DẪN CHẠY NHANH KHI CLONE DỰ ÁN

### 1. Di chuyển vào thư mục mã nguồn:
```bash
cd QuickCook_Source/QuickCook
```

### 2. Chọn một trong các cách chạy:
* **Cách 1 (Khuyên dùng)**: Chạy bằng Node.js:
  ```bash
  node serve.js
  ```
  Truy cập: **`http://localhost:5500`**
* **Cách 2**: Mở bằng **VS Code** > Nhấp phải `index.html` > Chọn **Open with Live Server**.
* **Cách 3**: Mở bằng **Visual Studio 2022** > Mở thư mục `QuickCook_Source/QuickCook` > Nhấp phải `index.html` chọn **View in Browser**.
* **Cách 4**: Mở trực tiếp file `index.html` trong trình duyệt Chrome / Edge.
